# 🛒 Hilmanesia Store

**Hilmanesia Store** adalah platform katalog dan pemesanan layanan digital/cetak berbasis web yang dirancang untuk mempermudah transaksi produk kreatif, cetak spanduk, banner, sticker, dan jasa desain secara cepat dan terintegrasi.

---

## 🚀 Fitur Utama

- 📦 **Katalog Produk Interaktif:** Menampilkan pilihan produk cetak dan jasa desain lengkap dengan spesifikasi teknis.
- 🧮 **Kalkulator Harga Otomatis:** Perhitungan estimasi biaya berdasarkan ukuran, bahan, dan kuantitas pesanan.
- 📲 **Integrasi WhatsApp Direct:** Langsung meneruskan detail pesanan ke WhatsApp admin dengan format pesan rapi.
- ⚡ **Responsif & Ringan:** Didesain agar nyaman diakses melalui perangkat seluler maupun desktop.

---

## 🛠️ Stack Teknologi

- **Frontend:** HTML5, Bootstrap 5, JavaScript (ES6+)
- **Backend / Automation:** Google Apps Script / Web APIs
- **Hosting / Storage:** GitHub Pages / Google Workspace / Drive API
